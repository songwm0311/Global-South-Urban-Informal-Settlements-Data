# Code availability statement

The accompanying code archive provides the region-neutral implementation used
for Sentinel-2 input validation, feature construction, U-Net training,
out-of-fold operating-point selection, prediction, independent segmentation
evaluation, and result visualization. UISI and GLCM mean/variance features are
implemented from the formulas supplied with the code deposit.

No original satellite imagery, third-party auxiliary dataset, regional
training sample, or reference label is redistributed in the code archive.
Authorized input files must be obtained separately from the sources documented
in the manuscript and Supporting Information and supplied through
`data_manifest.csv`.
